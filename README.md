# Coleoptera Geographic Information Recovery

This repository contains the Python workflow developed to recover missing geographic information in a global Coleoptera DNA barcode dataset.

The workflow combines text-based site geocoding, administrative centroid assignment, direct spatial overlay, PTP cluster-based realm inference, and a pilot validation of GBIF species-range-based inference.

## Workflow

1. **Site geocoding**
   - Generate unique locality queries.
   - Geocode raw queries using OpenStreetMap.
   - Clean unsuccessful queries and retry with OpenStreetMap.
   - Use Google Maps as a fallback.
   - Merge recovered coordinates into the original dataset.

2. **Administrative centroid assignment**
   - Identify records containing province- or country-level information.
   - Standardise administrative-area queries.
   - Assign Natural Earth administrative centroids.

3. **Direct realm overlay**
   - Overlay records with valid coordinates on the RESOLVE Ecoregions 2017 polygons.
   - Assign terrestrial biogeographic realms and prepare an update table.

4. **PTP cluster-based realm inference**
   - Evaluate inference accuracy using hidden-truth validation.
   - Classify predictions as High, Medium, Low, or Insufficient confidence.
   - Generate realm predictions for records lacking geographic information.

5. **GBIF species-range pilot**
   - Select a balanced pilot sample.
   - Match species names to GBIF taxa.
   - Download occurrence records.
   - Assign occurrences to biogeographic realms.
   - Evaluate prediction coverage and accuracy.

##Usage

Display the arguments and default paths for an individual script with:
python path/to/script.py –help
For example:
python scripts/05_gbif_realm_inference/pilot/00_prepare_pilot_candidates.py –help
Large input datasets and analysis outputs are not included in this repository.
Input and output paths can be supplied through each script's command-line arguments.
Google Maps geocoding requires an API key. The key must be supplied through the environment and must not be stored directly in the scripts or committed to the repository.

##Interpretation

Coordinate recovery methods generate approximate geographic coordinates at different spatial resolutions. Coordinates generated by administrative centroids represent province- or country-level locations and should not be identified as precise collection sites.
PTP cluster-based inference assigns a probable biogeographic realm using geographic evidence from related barcode records. It does not recover a new collection locality.
The GBIF workflow was evaluated as a pilot because large-scale occurrence retrieval was severely constrained by API rate limits and service availability.

##Data availability

The original barcode dataset and generated analysis output are not included due to the size and potential data-access restriction. This repository contains only the processing codes that required to reproduce the workflow when all the required data are available.
